## Heading

Talkie adds a heading with the timestamp to each minute of recording, formatted as

> YYYY-MM-DD HH:MM

## Order

We push the recordings to the file in chronological order, with the latest at the top of the file. This makes it much easier to read what happened most recently!

> Note: we also skip below any YAML information at the top of the file, so Talkie should preserve Obsidian header formatting.
